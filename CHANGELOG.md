## 0.2.0

- Standalone provider for Toonflow v2.0.10 with Qwen Image 2512/2.1 and MiniMax H3/Ref2VA, native binary results, image/audio references and public HTTPS video references.
- Standardized owned names and version-2 `task_id` recovery records while retaining version-1 recovery and exact host/Wylon protocol contracts. Generation POSTs are never automatically retried.
- Windows and macOS installation guidance, cross-platform Python tooling, Unicode paths, LF checksums and reparse-point protection.
- Optional version-guarded native reference-picker patch, bilingual installation and usage guides, and source packaging that excludes verification fixtures and credentials.
- MIT licensed; upstream HBAI-Ltd notices retained.
